# CHW Healthcare Toolkit

The CHW (Community Health Worker) Toolkit is an offline-capable, React-based clinical diagnostic assistant designed to help health workers screen patients, evaluate risks (like Hypertension and Diabetes), and manage follow-ups.

## Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Running the Project

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm run dev
   ```

3. **Open the app:**
   Open your browser and navigate to `http://localhost:5173` (or the URL provided in your terminal) to view the application.

## Technologies Used
- React (Vite)
- CSS (Vanilla, Offline-first design)
- Local State Management (No external APIs or databases required)
